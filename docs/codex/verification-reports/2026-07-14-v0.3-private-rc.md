## SBOM 缺口发现与修复

最初直接让 Syft 扫描 `dist/` 只得到 **1 package / 0 files**：它描述了归档容器，
没有真正枚举四个平台 archive 内的 Go binary，因此是不可接受的空壳供应链证据。

修复后的 release workflow 会：

1. 从四个 archive 各提取一个 `hukou` binary 到独立路径；
2. 断言提取出的 binary 数为 4；
3. 对该目录生成 SPDX 2.3；
4. 断言 SBOM 为 4 files，且 hukou、cobra、pflag、`golang.org/x/mod` 各有 4 套记录。

本地使用同一 Syft 1.46.0 路径验证后的最终结果为 **21 packages / 4 files**。远端
workflow 因 runner 计费阻断尚未执行，故这里只证明 workflow 契约与本地等价产物，
不声称 GitHub Actions 中的 SBOM job 已绿色。
