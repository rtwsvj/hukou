1. 临时启动原本停止的 Colima。
2. 使用相同 `golang:1.26.5-bookworm` image digest `sha256:18aedc16aa19b3fd7ded7245fc14b109e054d65d22ed53c355c899582bbb2113` 启动两个全新容器。
3. source 与 module cache 只读挂载；两个容器分别把 `DIST_DIR` 指向独立目录并运行正式 `scripts/release.sh`。
4. 对两个完整输出目录逐文件比较并分别校验 checksum。
5. 创建 Release、重新下载远端资产，再次逐字节比较和校验。
6. 停止 Colima 并确认恢复 not running。

两次最终脚本运行前有两组无效启动尝试：第一组把 Docker `-e` 放在镜像名后，容器未执行脚本；第二组使用 login shell 丢失 Go PATH，在首个 build 前退出。正式脚本会先清空各自输出目录，后续两次成功运行完全覆盖这些目录；无效尝试的内容未参与比较或上传。
