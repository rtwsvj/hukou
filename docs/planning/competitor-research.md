# 竞品调研总结（人话版）

> 状态：2026-08 调研完成。写给没有代码背景的人看，专业名词都有白话解释。

## 一句话结论

网上没有人和 hukou 干一模一样的事。别的软件都是帮你"装新程序"，hukou 是帮你"管已经在电脑里的、没人管的程序"——这个位置是空白的，是好事。

（背景复习：hukou = "软件户口本"。找出没人管的程序、给它们上户口，以后能一键升级，升级坏了能退回旧版本。）

## 三个重要发现

### 发现一：没有直接对手（好消息）

上面这些都在"装新程序"这条赛道上竞争。hukou 的赛道是"管已经在电脑里的程序"——盘点它们的来路、给它们上户口、升级、回滚。**这块没人占。** 而且有个叫 ubi 的软件自己在说明书里说："想按项目管版本请用 mise，我只管全局安装"——说明大家都默认各管一段，hukou 守住自己这段就稳。

### 发现二：唯一做了中文界面的，做法很简单，可以直接抄

13 个软件里，只有 topgrade 做了多语言界面（英文、中文简体、中文繁体等 7 种）。它的做法就是**一张中英对照表** + 一个"看系统语言自动切换"的小功能，没有高深技术。这正是我们做中文界面要抄的作业（详见《中文界面方案》）。

### 发现三：一个反面教材，提醒我们"别瞎猜"

有个叫 bvm 的软件死了，作者在主页写明死因：**它对程序的下载文件名字"猜得太自信"**（文件名千奇百怪，猜错就出问题），加上 Windows 上的麻烦解决不了，直接弃坑。

这正好印证 hukou 的一个原则：**认不出一个程序是谁家的，就老实说"不知道"，绝不硬猜**。hukou 现在就是这么做的（盘点时会把认不出的标成"未知"），这个原则要继续坚持。

## 值得抄的五份作业（人话版）

1. **搬家清单**（抄 gup、stew）：把电脑上"上过户"的程序导出成一张清单，换新电脑时一键照单恢复。→ 对应 B 队第 1 项。
2. **升级前先看说明**（抄 eget、ubi 的思路）：升级前让你先看这次更新改了啥；选安装包时多几道筛选，保证每次选的都是同一个正确的包。→ 对应 B 队第 3 项。
3. **一键升级的进度与失败提醒**（抄 topgrade）：升级过程一步步带标题显示，哪步失败一眼看到，并且把失败在输出里醒目标出、成功了不烦你。→ 对应 B 队第 4 项。
4. **指纹防掉包**（抄 aqua）：第一次上户口时记下程序的"指纹"（一串唯一编号），以后每次升级先核对，对不上就拒收。hukou 已经有核对能力，补上"上户口时首记指纹"这一步就行。→ 对应 B 队第 5 项。
5. **中文界面**（抄 topgrade）：就是《中文界面方案》那份文档说的做法。→ 对应 C 队。

## 调研中还纠正了两个常见误解

- 之前以为 topgrade 有"手机推送"功能——查证后发现它没有，它只有电脑桌面弹窗；**手机推送反而是 hukou 自己已经做好的功能**（notify 命令）。（补充：该手机推送功能已决定在 2026-08 发布前删除，理由是无真实使用场景——本记录保留调研当时的事实，最新取舍见《下一步计划》。）
- 之前以为 ubi 会"比较版本新旧"——查证后发现它不会；**版本比较这块 hukou 反而走在前面**。
