# V0.3 artifact and platform evidence

## Availability boundary

The original V0.3 RC artifacts are **not in Git and not in a GitHub Release**.
On the originating workstation they were retained under the ignored path:

```text
<originating-checkout>/dist/release-builds/v0.3.0-rc.1/
```

That path is informative only. A GitHub-only reviewer cannot access it and
must rebuild. Do not add large binaries to Git merely to satisfy this handoff.

## What a reviewer should return

- Independently generated archive and checksum hashes.
- Archive member lists, modes, and embedded `hukou version` output.
- Toolchain versions and source commit.
- Native-runtime rows actually exercised, without promoting cross-builds to
  runtime support.
- SBOM semantic assertions and the fresh SBOM file hash.
- Any mismatch explanation, including compiler, linker, tar, gzip, or source
  timestamp differences.
