### Tier D: reproducible archives

Use two fresh directories below a newly created temporary root. The release
script rejects a dirty worktree, requires GNU tar, and recursively deletes the
configured `DIST_DIR`; never point it at a directory containing other data.

```bash
(
  set -euo pipefail
  release_root="$(mktemp -d "${TMPDIR:-/tmp}/hukou-audit-release.XXXXXX")"
  test -n "$release_root" && test -d "$release_root"
  trap 'rm -rf -- "$release_root"' EXIT

  VERSION=v0.3.0-rc.1 DIST_DIR="$release_root/a" bash scripts/release.sh
  VERSION=v0.3.0-rc.1 DIST_DIR="$release_root/b" bash scripts/release.sh
  diff -qr "$release_root/a" "$release_root/b"

  test "$(find "$release_root/a" -maxdepth 1 -name '*.tar.gz' -type f | wc -l | tr -d ' ')" = 4
  test "$(wc -l < "$release_root/a/checksums.txt" | tr -d ' ')" = 4
  if command -v sha256sum >/dev/null 2>&1; then
    (cd "$release_root/a" && sha256sum -c checksums.txt)
  else
    (cd "$release_root/a" && shasum -a 256 -c checksums.txt)
  fi

  if tar --version 2>/dev/null | grep -q 'GNU tar'; then
    audit_tar=tar
  else
    audit_tar=gtar
  fi
  "$audit_tar" --version

  for archive in "$release_root/a"/*.tar.gz; do
    root="$(basename "$archive" .tar.gz)"
    members="$release_root/${root}.members"
    "$audit_tar" -tzf "$archive" >"$members"
    awk -v root="$root" '$0 != root && index($0, root "/") != 1 { exit 1 }' "$members"
    test "$(grep -Fxc "$root/hukou" "$members")" = 1
    unpack="$release_root/unpack-$root"
    mkdir "$unpack"
    "$audit_tar" -xzf "$archive" -C "$unpack"
    test -f "$unpack/$root/hukou" && test ! -L "$unpack/$root/hukou" && test -x "$unpack/$root/hukou"
    test -f "$unpack/$root/README.md"
    test -f "$unpack/$root/README.zh-CN.md"
    test -f "$unpack/$root/LICENSE"
    test -f "$unpack/$root/THIRD_PARTY_NOTICES.md"
    test -d "$unpack/$root/LICENSES"
    go version -m "$unpack/$root/hukou"
  done

  sbom_root="$release_root/sbom-root"
  mkdir "$sbom_root"
  for archive in "$release_root/a"/*.tar.gz; do
    root="$(basename "$archive" .tar.gz)"
    "$audit_tar" -xzf "$archive" -C "$sbom_root" "$root/hukou"
  done
  test "$(find "$sbom_root" -type f -name hukou | wc -l | tr -d ' ')" = 4
  syft "dir:$sbom_root" -o "spdx-json=$release_root/audit.spdx.json"
  jq -e '
    .spdxVersion == "SPDX-2.3" and
    (.files | length) == 4 and
    ([.packages[] | select(.name == "github.com/rtwsvj/hukou")] | length) == 4 and
    ([.packages[] | select(.name == "github.com/spf13/cobra" and .versionInfo == "v1.8.1")] | length) == 4 and
    ([.packages[] | select(.name == "github.com/spf13/pflag" and .versionInfo == "v1.0.5")] | length) == 4 and
    ([.packages[] | select(.name == "golang.org/x/mod" and .versionInfo == "v0.38.0")] | length) == 4 and
    all(.files[]; any(.checksums[]; .algorithm == "SHA256"))
  ' "$release_root/audit.spdx.json" >/dev/null
  jq -r '.packages[] | [.name, (.versionInfo // "UNKNOWN")] | @tsv' \
    "$release_root/audit.spdx.json" | sort
  jq -r '.relationships[] | [.spdxElementId, .relationshipType, .relatedSpdxElement] | @tsv' \
    "$release_root/audit.spdx.json" | sort
)
```

The block verifies all four archive roots, executable topology, licenses,
READMEs, checksum coverage, Go build metadata, and SBOM structure. The custom
`hukou version` value (version/commit/date) requires compatible/native execution
or a separately justified emulator; record only the targets actually executed.
The original hashes are in the verification report; a different Go toolchain,
target-feature environment, gzip implementation, or GNU tar version may explain
a byte mismatch and must be recorded rather than ignored.

Regenerate the SBOM from the four extracted binaries with Syft 1.46.0 and
verify SPDX 2.3 semantics. Syft embeds creation metadata and a document
namespace, so semantic equality (21 package records / 4 binary files in the
recorded run) is reproducible; byte identity of a newly generated JSON file is
not expected.

`go version -m` is a static build-information inspection and works for
cross-target binaries; it is not native execution. Run `hukou version` only on
a compatible/native target and report which targets actually executed.

## 6. Safe behavioral testing

Most Go tests use `t.TempDir`, `httptest.Server`, and `HUKOU_DATA_DIR`. For
manual CLI smoke tests, always create an isolated environment:

```bash
(
  set -euo pipefail
  audit_root="$(mktemp -d "${TMPDIR:-/tmp}/hukou-audit-smoke.XXXXXX")"
  test -n "$audit_root" && test -d "$audit_root"
  trap 'rm -rf -- "$audit_root"' EXIT
  audit_home="$audit_root/home"
  audit_data="$audit_root/hukou-data"
  audit_bin="$audit_root/bin"
  mkdir -p "$audit_home" "$audit_bin"
  go build -trimpath -o "$audit_bin/hukou" ./
  env HOME="$audit_home" HUKOU_DATA_DIR="$audit_data" "$audit_bin/hukou" version
  env HOME="$audit_home" HUKOU_DATA_DIR="$audit_data" "$audit_bin/hukou" doctor --json
  test ! -e "$audit_data"
)
```

Create disposable fixture executables only. Never adopt or upgrade a real
package-manager binary as part of the audit.
