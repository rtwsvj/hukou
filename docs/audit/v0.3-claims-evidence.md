# V0.3 claims-to-evidence map

## How to use this map

Every claim below is a review hypothesis, not a request to trust the original
author. Inspect the pinned code subject, rerun the listed tests, and try to
falsify the invariant. Source paths identify implementation seams; test names
identify existing evidence and likely blind spots.
