# 压力测试记录：第三层 · 并发与崩溃注入（P0 数据安全）

> 日期：2026-08-14。攻击台已入仓库 `scripts/stress/`（沙盒隔离，绝不触碰真实系统）。
> 被测对象：包含故障注入暂停点（`HUKOU_STRESS_PAUSE`，默认零影响）的构建。
> 判定口径：每次攻击后——①只读体检不崩溃 ②下一个写命令能自动恢复并成功
> ③终态体检健康 ④账本合法 ⑤语义收敛到"前"或"后"完整状态。

## 1. SIGKILL 崩溃断点扫射（本地收编路径）

- 相位：`post-prepared`（PREPARED 已落盘、备份已写）、`pre-commit`（账本就绪、
  COMMIT 未写）、`post-commit`（COMMIT 已落盘、未清理）、`pre-finalize`（清理前）。
- 规模：4 相位 × 20 次 = 80 次 SIGKILL。
- 结果：**80/80 通过**。

### 发现并修复的缺陷（P0）

**崩溃回滚残留**：在 `post-prepared` 相位杀死收编进程后，PREPARED 回滚删除了
原始备份文件，却留下了它创建的空目录链 `store/<name>/original/`，最终体检报
`STORE_ARTIFACT_LAYOUT_INVALID`（20/20 复现）。

修复：`internal/transaction/recover.go` 的"回滚为缺失"路径在移除资源后，
向上清理**它自己创建的空目录**——边界写死：绝不触碰数据根的直接子目录
（store/、transactions/ 等），遇到第一个非空目录立即停止。配套 2 组回归测试
（边界保护、非空即停）。修复后扫射 80/80 收敛干净。

## 2. 锁风暴（16 进程并发抢锁）

- 结果：**通过**。1 个成功、15 个立刻收到"状态被锁定"并快速失败、0 挂起、
  0 意外错误、耗时 <1s、终态体检健康、账本条目数与成功数一致。

| state.lock 换成指向账本内文件的符号链接 | ✅ 拒绝 |

## 4. TOCTOU 竞速（升级暂停点偷换活动文件）

- 攻击：升级停在 `pre-activate` 时，外部进程把活动文件整体换成另一内容。
- 结果：**完美 fail-closed**——`resource has unknown drift … refusing
  overwrite`：升级拒绝、账本保持旧版本、被偷换的文件原样保留（零覆盖）、
  doctor 如实报告外部漂移。
- 印证了文档已承认的窄窗口之外的任何检测时机，hukou 的日志级状态复验都能兜住。

## 5. 升级路径崩溃断点扫射（真实网络）

- 相位：`pre-activate`（版本已入库、活动文件未替换 → 应回滚到旧版）、
  `post-commit`（应前滚到新版）。
- 规模：2 相位 × 5 次，真实 GitHub 下载 ripgrep 资产。
- 结果：**10/10 通过**（pre-activate 5/5 回滚到 15.1.0；post-commit 5/5 前滚到 15.2.0）。

## 6. 第一层：命名与文件系统攻击

**名称地狱（scan/adopt 29 项）**：制表符/换行/ESC 注入名、251 字节长名、纯空格、
尾部空格、RLO 方向覆盖字符、emoji/CJK、`-rf`、`~`、`*.txt`、反引号/`$(…)`/分号
命令注入样式名——scan 全数安全处理（表格零 ESC/CR 泄漏、JSON 合法、坏链接/
FIFO/套接字如实列入 skipped 并给原因）；adopt 对管道/套接字/目录/断链/自环/
互环/1000 层深链/指向 /dev/null 与目录的链接全部干净拒绝；合法怪名全部正常收编，
终态体检健康。

**发现并修复的缺陷（P1）**：纯空格名能通过收编校验、却在更晚的事务层被拒，
留下空目录残留（与 L3 同族的"晚拒绝残留"）。修复：`store.ValidateName/ValidateTag`
在源头拒绝"全空白"与"含控制字符"的名称（含 DEL），收编在任何写入前失败且零残留；
配 2 组回归测试（store 层矩阵 + cmd 层零残留断言）。

**大小写陷阱**：APFS 大小写不敏感，`Foo` 与 `foo` 无法在磁盘并存、陷阱无法构造；
检查逻辑由 `internal/doctor` 单元测试覆盖（确定性大小写别名 fixture）。

**卷权限极限**：只读 bin 目录 scan 存活；只读数据目录 adopt 干净拒绝。
**ENOSPC**：沙盒无 hdiutil，标记为环境未执行（列入 Linux CI 恢复后的待跑清单）。

## 7. 第二层：数据与协议喂毒

**畸形账本（35 种，黑盒毒杀 doctor/list/export）**：重复 JSON 键、NaN/Infinity、
1000 层嵌套、5MB 巨档、非 UTF-8、BOM、截断/尾随垃圾、schema 0/1/2/3/99/-1/x/null、
负保留深度、坏时间戳、坏指纹、`. /../ original` 标签、重名/路径错配、前向父事件/
环、无资产却声称已校验、未知字段、v1 携带 v2 字段走私——**35/35 全部按预期
fail-closed**：不崩溃、`--json` 永远合法、毒文件与备份逐字节未动、语义攻击
（走私/前向父/坏标签）全部精确命中对应诊断码。

**校验文件毒杀（18 种）**：CRLF/无尾换行/制表符分隔/大写摘要/注释空行/重复条目
（同摘要放行、冲突拒绝）/缺文件名/GNU 格式（有意的兼容支持）/BOM/百万字符长行
（扫描器 64KB 上限兜底）/坏十六进制/短摘要/空文件/纯注释；裸摘要伴生文件单条放行、
多条拒绝。全部符合预期——解析器兼容性好但绝不"大概对"。

**压缩炸弹**：600MiB 高倍率炸弹（压缩后 ~600KB）→ 解压在 512MiB 预算处干净
拒绝、无 OOM、无残留；`../`、绝对路径、`a/../../` 穿越全部拒绝且未在目标目录
外写任何文件；符号链接/硬链接条目不落地（只取普通文件）；100 层深目录安全；
截断 gzip/空包/纯垃圾流全部干净报错。

**伪造发布**：主机白名单禁止黑盒指向本地假服务器（这是安全特性本身），该路径
由既有进程内 e2e 套件覆盖（伪造元数据/404/校验不符/分页超限/重定向环），
本批以既有测试为准，未重复造轮子。

## 10. 第六层：界面与多语言极限

**全命令矩阵（18 条命令 × 中英双模式）**：每条命令两种语言的退出码一致；
所有 `--json` 输出**跨语言逐字节一致**（机器契约）；文本模式行数一致。

**发现并修复的缺陷（P1）**：`doctor --json` 的诊断消息曾随语言变化（消息在模板层
被本地化后写入 JSON），破坏"JSON 与语言无关"的机器契约。修复：`Finding` 保存
规范英文消息（JSON 值）+ 模板与参数（`json:"-"`），文本渲染器在渲染时按当前
语言重渲染——**JSON 恢复逐字节一致，文本模式中文照常**。配既有 doctor 测试
回归（消息断言不变）。

**中文表格对齐**：表头"路径"列与每行路径列的显示宽度前缀完全一致（宽字符按
双列计），中文下无错列。

**窄终端**：COLUMNS=20/40 不崩溃、退出码正常（表格不依赖终端宽度）。

**管道提前关闭**：`scan | head -1` 标准 SIGPIPE 行为（退出码 0/141），无 panic、
无垃圾输出。

**语言环境冲突矩阵（6 组合）**：`HUKOU_LANG` 显式优先（zh 压过 C、en 压过
zh_CN）、`LC_ALL` 压过 `LANG`、未知显式值回退英文、系统 zh 自动中文、C 环境
英文——全部符合设计。

**30/30 全过。**

## 复跑方式（攻击台已入仓库）

```sh
make stress                    # 全部六层（约 20 分钟；L3 升级扫射/L5 需真实网络与 gh 登录）
make stress SKIP_NETWORK=1     # 跳过需网络的三组（约 5 分钟）
```

- 沙盒自动开在临时目录（跑完可整目录删除）；结果汇总在 `results.tsv`，各层日志在
  同一目录的 `log/`。
- 网络层自动沿用 `gh auth token`；离线层无任何网络依赖。
- `HUKOU_BIN`/`STRESS_ROOT` 环境变量可指定被测二进制与沙盒根（默认用 `make build`
  的产物与临时目录）。
